Room / Circle — Call kab start, kab band?

Direct call, instant circle, scheduled meeting, host actions — sab rules ek jagah. Pehle samjho abhi kya chal raha hai, phir kya implement karna hai.

Pehle 4 words samjho

Lobby

Room me ho, wait / preview — video call abhi nahi (8 PM se pehle).

Live session

Asli call — RTC, camera, mic. Timer yahi se start hota hai.

Booking

Calendar slot: 8 PM start, 10 PM tak. Banate waqt fix.

Part A — Aaj code me kya hai Abhi

A1 — 2h join grace (meeting start hi nahi hui)
  • 8 PM scheduled, par kabhi live nahi hui
  • 8 PM + 2 ghante → circle expired
  • Alag hai “room khali 2 ghante” se — woh alag rule (B3)
A4 — Host “End for everyone”
Instant circle

Poora end — sab disconnect, SFU band

Scheduled circle

Live band, slot calendar me reh sakta hai (wapas scheduled)

A2, A7 — expires_at & Redis 2h
  • expires_at — circles ke liye; direct often null
  • Expired → join/token band, par har baar call se nahi nikalte
  • Redis ROOM_TTL = 2h — sirf cache, call end rule nahi

Golden rules Target

  1. Per session — har live call ki apni max duration
  2. Booking window — scheduled: 8–10 PM jaisa slot
  3. Host end — button = turant band (instant = poora end)
  4. Khali room 2h — scheduled, koi active nahi → room end
  5. Naya session — sab gaye, dubara live = naya timer (booking ke bahar mat jao)

6:01 wala sawal — dubara start?

Haan, naya session = naya 3 ghante

Lekin scheduled me 10 PM ke baad dubara live nahi. Aur 8 PM se pehle sirf lobby (recommended).

Scheduled circle — do clocks

Calendar (booking)

8 PM – 10 PM fix. 10 PM ke baad call nahi.

Session (live)

3 PM live → 6 PM = 3h cap. Lekin calendar ke hisaab se 10 PM tak allow.

// Scheduled — end time
session_end   = live_started_at + 3 hours
calendar_end = scheduled_end (ya start + expiration minutes)
expires_at    = min(session_end, calendar_end)   // jo pehle aaye, wahan band

Implementation checklist

  • Constants: DIRECT 2h, CIRCLE 3h, EMPTY 2h
  • computeSessionExpiresAt(room)
  • Set expires_at on create / mark live / expand
  • Empty room 2h + reset on join
  • Auto-end: teardown, not only is_expired
  • Direct: RTC token check expired
  • Host end instant: always ended + teardown
  • Client warnings 15m / 5m (optional)
  • reconcileRoomSessionOnAccess — join + token + GET
  • endLiveRoomSession — idempotent teardown
  • R5 — 0 active, khali ≥ 2h
  • Join errors — reason-specific messages
